## 💡 Хотелки (крупные идеи, эксперименты)

### X1. Блочный редактор вместо TinyMCE
Заменить TinyMCE на блочный редактор (Notion-like, Gutenberg-style). Каждый
элемент контента — блок (параграф, заголовок, картинка, видео, цитата),
с drag-and-drop, вложенными блоками, слэш-меню.

**Кандидаты:**
- Yiitap (Notion-style, на Tiptap/ProseMirror).
- Blok (headless, кастомный интерфейс).
- Tiptap (с нуля, база).
- Gutenberg (ориентир).

**Следствие:** смена архитектуры хранения контента. Вместо HTML-строки в
БД — JSON с описанием блоков. Переписывание логики рендеринга статей.

**Приоритет:** 💡 идея (не срочно).

### X2. Утилита проверки привязанных шар
Утилита в админке для сканирования `ShareAttach` — список файлов с
привязками к статьям/страницам, действия (отвязать, редактировать,
перейти). Обратный отчёт «файлы без привязок».

**Приоритет:** 💡 (уже фигурирует в вишлисте как W33 — перенести сюда
или оставить в обоих?).

### X3. Криптопровайдер (ЭЦП)
Интеграция КриптоПро для подписи документов/файлов.

**Приоритет:** 💡.

### X4. Почта (Postfix + Dovecot + Roundcube + mail/ Flask-UI)
Полноценный почтовый сервис в экосистеме.
