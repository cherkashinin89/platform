## W42 — Утилита чистки мусора (плагин / внешняя утилита)

**Цель:** помочь админу находить и удалять «мёртвые» данные, которые копятся в проекте.

**Что входит:**

1. **Мёртвые Maildir'ы почты** — директории `/var/vmail/<domain>/<local_part>/`, для которых **нет** записи в `mailbox` (пользователь удалён, Maildir остался).
   - Показать список: домен, local_part, размер, дата последнего изменения.
   - Кнопки: «Удалить», «Заархивировать + удалить».
   - **Контекст:** при удалении пользователя Maildir **не удаляется** (Вариант A), архив кладётся в `_mail_archive` у админа. Если админ решил не архивировать — Maildir остаётся мусором.

2. **Мёртвые шары (`CloudShare`)** — шары, у которых **нет** `ShareAttach` и которые **не используются**.
   - Показать: токен, файл, дата создания, размер.
   - Кнопка «Удалить».

3. **Мёртвые `FileUsage`** — записи, ссылающиеся на **несуществующие** сущности (статьи/страницы, которых уже нет).
   - Показать: file_id, entity_type, entity_id.
   - Кнопка «Удалить».

4. **Мёртвые `CloudFile`** — записи в БД, у которых **нет** файла на диске (`stored_name` не найден).
   - Показать: имя, владелец, размер в БД.
   - Кнопка «Удалить запись».

5. **Осиротевшие файлы на диске** — файлы в `cloud_data/<uid>/`, для которых **нет** записи в `cloud_file`.
   - Показать: путь, размер, дата.
   - Кнопка «Удалить».

6. **Старые архивы в `/tmp`** — `.tar.gz` от неудачных операций.
   - Показать: имя, размер, дата.
   - Кнопка «Удалить».

**Формат:** отдельная страница в админке `/admin/maintenance/` + периодическая проверка (cron / systemd timer) с уведомлением админа.

**Оценка:** 1–2 дня.

**Приоритет:** низкий — не критично для работы, но полезно для обслуживания.

**Связано:** W2 (почта), W15 (бэкап почты), W33 (утилита ShareAttach).
