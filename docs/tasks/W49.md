# W49 — Мобильный UI почты

**Дата:** 2026-10-15
**Статус:** запланировано
**Приоритет:** средний

---

## ЦЕЛЬ

Отдельный **mobile-first** UI для почты (не адаптив, а **отдельный** шаблон).

**Сценарий:**
1. Пользователь **открывает** почту **с** телефона.
2. **Один** экран = **одна** панель (папки → список → письмо).
3. **Touch-friendly** кнопки.

---

## ЗАДАЧИ

1. **Определение** mobile (User-Agent).
2. **Отдельные** шаблоны `mail/templates/mobile/`.
3. **Одна** панель за раз.
4. **Навигация:** кнопка «Назад» (стрелка в шапке).
5. **Touch-friendly:** кнопки ≥ 40px.
6. **Адаптация** просмотра писем.
7. **Полноэкранные** формы.
