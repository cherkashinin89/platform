# W35 — Закрытая шара (пароль, срок, лимит)

**Дата:** 2026-10-28
**Статус:** запланировано
**Приоритет:** средний
**Связано:** W48 (Collabora), W58 (X-Accel-Redirect), W59 (просмотр)

## ЦЕЛЬ

Дать возможность делиться файлом облака по ссылке с ограничениями:
- **Пароль** (защита от «кто угодно с ссылкой»).
- **Срок действия** (ссылка перестаёт работать через N дней).
- **Лимит скачиваний** (после N скачиваний ссылка умирает).

Два режима доступа:
1. **Публичная шара** (`is_public=True`) — работает **без логина** (аноним открывает `/s/<token>`).
2. **Только для залогиненных** (`is_public=False`) — требует SSO (логин в проекте).

## КОНЦЕПЦИЯ (согласовано)

- **Публичная шара** — для просмотра/скачивания. **Не** даёт редактирования (редактирование — только W48, для залогиненных).
- **Залогиненные** — могут смотреть/скачивать (если `can_edit=False`) или редактировать (если `can_edit=True` и W48).
- **Анонимы** — только просмотр/скачивание (если `is_public=True`).

## МОДЕЛЬ `CloudShare` (общая с W48)

Поля (уже есть в `core/models.py`):
- `token` (уникальный), `file_id`, `created_by_id`, `created_at`.
- `expires_at` (срок), `password_hash` (Argon2id, опционально), `download_count`, `max_downloads`.
- `can_edit` (W48) — разрешено ли редактирование.
- **`is_public`** (W35 — **добавить**) — доступна ли анонимам.

**Миграция:** `add_column('cloud_share', 'is_public', Boolean, default=False)`.

## РЕАЛИЗАЦИЯ

### 1. UI создания шары (облако)

Модалка `openShareModal` (в `cloud/templates/index.html`):
- Чекбокс «Публичная ссылка (без логина)» → `is_public`.
- Поле «Пароль» (опционально) → `password_hash`.
- Поле «Срок действия (дней)» → `expires_at`.
- Поле «Лимит скачиваний» → `max_downloads`.

### 2. Эндпоинт создания шары (`cloud/app.py`)

`POST /api/share/<file_id>` — принимает `is_public`, `password`, `expires_days`, `max_downloads`, создаёт `CloudShare`.

### 3. `/s/<token>` (framework или cloud?)

Сейчас `/s/<token>` — в **framework** (публичная страница). Для **W35** нужно:
- Если `is_public=False` — редирект на логин (SSO).
- Если `password_hash` задан — форма ввода пароля (сессия `share_access_<token>`).
- Если `is_expired()` — сообщение «Ссылка истекла».
- Если `download_count >= max_downloads` — сообщение «Лимит исчерпан».
- Иначе — скачивание (или просмотр, W59).

### 4. Инкремент `download_count`

При скачивании через `/s/<token>` — `increment_share_download`.

## ОГРАНИЧЕНИЯ

- **Не** даёт редактирования анонимам (только просмотр/скачивание).
- **Не** заменяет W48 (редактирование — отдельно, для залогиненных).
- **Не** требует новой таблицы (только `is_public` в `CloudShare`).
