# W48 — Совместное редактирование файлов (Яндекс.360-like)

**Дата:** 2026-10-15
**Статус:** запланировано
**Приоритет:** средний

---

## ЦЕЛЬ

Возможность **нескольким** пользователям **одновременно** редактировать **один** файл (Excel, Word, документы).

**Сценарий:**
1. Создатель файла **отправляет** **шару** получателям.
2. Получатели **открывают** ссылку → **редактируют** в **реальном** времени.
3. **В** **облаке** отправителя — **всегда** **актуальная** версия.

---

## ЗАДАЧИ

1. **Онлайн-редактор** — OnlyOffice / Collabora / свой.
2. **WebSocket** — real-time синхронизация.
3. **Версионирование** — история изменений.
4. **Права** — кто может редактировать / только читать.
5. **Блокировки** — concurrent edits.
6. **Формат** — docx, xlsx, pptx.

---

## ОЦЕНКА

**Большая задача.** 1–2 месяца (при работе только над ней).

**Зависимости:**
- OnlyOffice Document Server (~2 ГБ RAM, Docker).
- Или Collabora Online.
- Свой редактор — **год+**.
