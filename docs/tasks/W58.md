# W58 — X-Accel-Redirect: ContentFile вместо ShareAttach

**Статус:** выполнено (2026-10-28, коммиты bc71da8, 49a7c52).
**Связано:** W3 (заменено), W35, W48, W59.

## Цель

Убрать костыли прикрепления файлов к статьям/страницам: вместо ShareAttach (шара на каждый файл) — прямая привязка ContentFile; отдача файлов через /files/<id> с X-Accel-Redirect (Nginx отдаёт файл, Python не стримит).

## Что сделано

- core/models.py: модель ContentFile (file_id, target_type article/page, target_id); удалён ShareAttach.
- core/migrations: content_file, drop share_attach.
- framework/app.py: /files/<id> (X-Accel-Redirect), _process_attached_files_in_html (href=/files/<id>).
- cloud/app.py: api_check_attachments на ContentFile; /attached только для editor.
- cloud/cloud_service.py: list_attached_shares -> файлы (ContentFile).
- core/static/js/attached-files.js: makeArticleFileTile (href=/files/<id>), убраны data-share-token и навигация по папкам в статье.
- nginx: location /protected_files/ (internal, alias cloud_data).

## Связанные

- W3 — прикрепление файлов через ShareAttach (устарело, заменено).
- W48 — WOPI/Collabora (использует CloudFile).
- W59 — просмотр офисных файлов (read-only).
