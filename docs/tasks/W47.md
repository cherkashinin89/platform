# W47 — UI почты (полный, Gmail-like)

**Версия:** v1
**Дата:** 2026-10-15
**Статус:** запланировано
**Приоритет:** высокий

---

## 1. ЦЕЛЬ

Полноценный веб-интерфейс для работы с почтой:
- Чтение, отправка, ответы, пересылка.
- Папки (стандартные + свои).
- Sieve-правила.
- Поиск (IMAP SEARCH).
- Вложения (local + облако).
- Черновики.
- Уведомления (toast, счётчики).

---

## 2. АРХИТЕКТУРА

### 2.1. Где живёт UI

- **UI почты** — в **mail-сервисе** (`mail.site.ru`).
- **Админка** — **только** в **framework** (`/admin/`).
- **Никаких** админок в mail.

### 2.2. Аутентификация

- **SSO через cookie** (`session`).
- Своей формы логина **нет**.
- Если не залогинен → редирект на `site.ru/login`.
- Один пароль (Argon2id) для всей экосистемы.

### 2.3. Доступ к IMAP

- **Master-user** в Dovecot.
- Mail-сервис подключается как `master*user@domain`.
- Пароли пользователей **не хранятся**.

### 2.4. Отправка

- **`sendmail -f <from> -t`** (Postfix, local).
- Копия в Sent — через IMAP `APPEND`.
- Rate limit — 100 писем/час на пользователя.
- Проверка `From:` — только свои адреса.
- При ошибке — toast пользователю, лог `mail_send_fail`.

### 2.5. Просмотр письма (безопасность)

- **`bleach`** — очистка HTML.
- **CSP** — заголовки.
- **Блокировка картинок** по умолчанию (tracking pixels).
- Ссылки — `target="_blank" rel="noopener noreferrer"`.
- **Iframe sandbox** — позже (отдельная задача).

### 2.6. Хранение состояния UI

**Модель `MailUiState`:**
```python
class MailUiState(db.Model):
    __tablename__ = 'mail_ui_state'
    id = db.Column(db.Integer, primary_key=True)
    user_id = db.Column(db.Integer, db.ForeignKey('user.id', ondelete='CASCADE'),
                        nullable=False, unique=True, index=True)
    sort = db.Column(db.String(20), default='date')
    dir = db.Column(db.String(5), default='desc')
    filters = db.Column(db.JSON, nullable=True)
    per_page = db.Column(db.Integer, default=50)
    updated_at = db.Column(db.DateTime, default=datetime.utcnow, onupdate=datetime.utcnow)
Что хранится: сортировка, фильтры, per_page.
Что не хранится: последняя папка (всегда INBOX), номер страницы (всегда 1).

class ErrorLog(db.Model):

                               nullable=True)
Пользовательские ошибки → честный текст + код.
Системные ошибки → только код.

3. ФУНКЦИОНАЛ
3.1. Список папок
Стандартные: INBOX, Sent, Drafts, Trash, Junk.

Свои: создание, переименование, удаление, вложенные.

Счётчик N/M (непрочитанные жирным / всего).

Жирный шрифт для непрочитанных.

3.2. Список писем
Одна строка = письмо.

Чекбокс, звёздочка (важное), отправитель, тема, вложение (иконка), дата.

Пагинация (50/page, настраиваемо).

Сортировка (по дате, отправителю, теме).

Направление (asc/desc).

3.3. Просмотр письма
Заголовок, мета (от, кому, дата).

Кнопки: Ответить, Reply-All, Переслать, Удалить, Переместить.

Тело (HTML bleach / plaintext).

Вложения (список, скачать, сохранить в облако).

Кнопки ответа внизу.

3.4. Отправка
To, Cc, Bcc (автодополнение из истории).

Subject.

Body — Quill.

Вложения:

≤ 30 МБ → MIME (RAM, temp).

30 МБ → модалка выбора папки облака → загрузка → ссылка /s/<token>.

Кнопки: Отправить, Сохранить черновик, Отмена.

3.5. Черновики
Автосохранение каждые 30 сек.

beforeunload — при закрытии.

Восстановление при открытии /compose.

Удаление после отправки.

Идентификация — UID IMAP.

3.6. Поиск
Простой: одно поле (FROM, SUBJECT, BODY).

Лимит 500 результатов.

FTS — W51.

3.7. Sieve-правила
UI: /settings/rules — карточки.

Условия: From, To, Cc, Subject, Body, Size, Has attachment.

Операторы: содержит, не содержит, равно, matches.

Действия: переместить, пометить, удалить, переслать.

Приоритет — drag&drop.

3.8. Настройки
Профиль (просмотр).

Пароль — только админ (информация).

Подпись (в MailSettings).

IMAP/SMTP настройки.

Ссылки на /settings/rules, /settings/folders.

3.9. Уведомления
Toast при новом письме (5–10 сек, rate limit 1/5 мин).

Счётчик в шапке — везде (site, cloud, mail).

Polling 60 сек (боевой — 15–30).

3.10. Унификация модалки облака
file_manager_modal.html — единая для статей и почты.

Панель действий, кнопки на плитках, хлебные крошки, drag&drop.

Параметр mode: attach_to_article | attach_to_email | upload_to_cloud.

Callback on_select.
