**Дата:** 2026-10-15

**Приоритет:** средний

## ЦЕЛЬ

Быстрый **полнотекстовый** поиск по **телу** писем (сейчас — IMAP SEARCH, медленно на больших ящиках).

---

## ЗАДАЧИ

1. **Dovecot FTS** — плагин `dovecot-fts`.
2. **Backend:** Flatcurve (лёгкий) или Xapian.
3. **Индексация** — в фоне.
4. **UI:** расширенный поиск (From, To, Subject, Body, Date, Flags).
5. **Морфология** — русский язык.
6. **Ранжирование** — по релевантности.
