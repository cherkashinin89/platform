---

## 1. ЦЕЛЬ

Объединить галерею: альбом = папка облака (`Альбомы/<имя>`), фото = файлы папки. Убрать `Photo` (двойное владение). Слайдер сохранить 1:1.

Альбомы создаются в статье (в процессе работы) и автономно (для `/gallery`). На сайте — раздел галереи.

---

## 2. МОДЕЛЬ (пересоздание с нуля)

`Photo` — **удаляется**. `article_albums` (M2M через Photo) — **удаляется**. `Album.cover_photo_id` — **удаляется**.

### Album (новая)

- `id`, `title`, `slug` (unique), `description`
- `author_id` — FK user (SET NULL)
- `cloud_folder_id` — FK cloud_file (`Альбомы/<имя>`, SET NULL)
- `cover_file_id` — FK cloud_file (SET NULL)
- `is_published`, `order`, `created_at`
- `archived_at`, `deleted_at` — архив/корзина (как у статей)
- M2M `articles` (связь со статьями)

### SliderFeature

- `file_id` — FK cloud_file (CASCADE)
- `added_by_id` — FK user (SET NULL)
- `added_at`
- Лимит 10, вытеснение по `added_at.asc()` (старейшее теряет ★ и обложку)

### Системная папка

- `SYSTEM_FOLDERS` += `album: Альбомы` (по аналогии со Статьи/Страницы).

---

## 3. СЛАЙДЕР (сохранить 1:1)

- ★ на фото = `Album.cover_file_id` (обложка) + `SliderFeature` (слайдер) — одна кнопка, два эффекта (как сейчас).
- Лимит 10; при превышении старейшее (`added_at.asc()`) теряет ★ и обложку (обложка → первое фото папки).
- Снятие ★: снимается, обложка → первое фото папки.
- `SiteSettings.get_slider_photos()` → `SliderFeature` (10, `added_at.desc()`).
- `base.html` — рендер слайдера без изменений (источник — SliderFeature).

---

## 4. ЛОГИКА

- Создание альбома (в статье или автономно): создать/выбрать папку `Альбомы/<имя>` → `Album.cloud_folder_id`.
- Наполнение: файлы в папке альбома (через Redactix-механизм: upload/browse/copy).
- В статье: галерея **ссылается на папку альбома** (файлы оттуда); M2M `Album.articles`.
- Архив: `Album.archived_at`; при архивации статьи — архивировать её альбомы (если не связаны с другими активными статьями).
- Корзина: `Album.deleted_at` (папка → корзина облака). Симметрия: облако ↔ альбом.
- Публичная галерея `/gallery`: список альбомов (папок `Альбомы/*`), `/gallery/<slug>` — файлы папки.
